MachO-explorer — the reader runs in this tab

Drop an Apple binary below. It is read here, in your browser — the bytes never leave this machine and nothing is uploaded. The parser is not a reimplementation: it is the actual src/macho.mjs, linked with a small host shim so it runs with no Node and no network. Audit it yourself below.

thin or universal · arm64, arm64e, x86_64, i386, armv7, ppc · macOS, iOS, watchOS, tvOS, visionOS

Audit it yourself

The claim of this demo is not "it has a UI". It is that the code that read your file is small enough to read. The bundle is generated mechanically from the three source modules by demo/link.mjs — no logic is copied, so the file you audit is the file that ran. Click a file to view it (served from this repository, not fetched from a CDN).
